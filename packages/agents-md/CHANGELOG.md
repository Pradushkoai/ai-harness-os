# Changelog — agents-md

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-09-30

### Added
- Анализатор проектов: типы `1c-edt` (`Configuration.mdo`/кластер `.mdo`), `1c-xml` (`Configuration.xml`), `python` (pyproject: имя + requires-python), `js-ts` (package.json/tsconfig), `generic` (fallback). Приоритет 1C > python > js-ts. Маркеры тулинга: тест-раннеры, CI, Docker, линтеры; для 1С автоматически `bsl-language-server`.
- Структурный сканер: топ-уровень каталогов, RU-комментарии для 1С-директорий метаданных (`Catalogs → Справочники` и др.), счётчики файлов и доминирующие расширения; ограничен (2000 файлов, скрытые/мусорные каталоги пропускаются).
- Генератор AGENTS.md (RU, чистый stdlib, без шаблонизатора): Overview / Setup / Architecture (дерево) / Code Style / Testing / Common Tasks / Do NOT / Log — по типу проекта. Сгенерированный файл валиден по собственному валидатору (гарантировано тестами всех 5 типов).
- Валидатор: существование + UTF-8, лимит 32 KiB (каскадный лимит стандарта), обязательные разделы (RU-алиасы принимаются: «Обзор», «Тестирование» и т.п.), предупреждение о слишком коротком файле.
- CLI `agents-md init [--force|--stdout]` / `agents-md validate [--file]`, exit 0/1/2; `--version` на корневом и сабпарсерах (урок bsl-check).
- 82 юнит-теста на герметичных tmp-проектах (без сети): фикс-фабрики пяти типов проектов, прямое покрытие валидатора (UTF-8, 32 KiB, RU-алиасы разделов, предупреждения) и структурного сканера (skip-лист, маркеры расширений, границы дерева, `src_dir`).
