# Changelog — harness-mcp

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.1.2] — 2026-10-05

### Changed
- Тестовый двойник `FakeLoop` следует новому контракту `BslAgentLoop.run(env_note=...)` (harness-loop 0.13.1): до фикса engine-note занимал контекст-сокет в eval — теперь отдельный параметр; двойник его принимает, поведение тулингов MCP не изменилось.

## [0.1.1] — 2026-10-05

### Changed
- **Верификатор тулинга `verify_module` по умолчанию игнорирует LS-ложноположительные коды** (`bsl_verify.LS_FALSE_POSITIVE_CODES`, em-dash в комментариях — ERROR для LS при работающем рантайме; находка пилота УТ 11). Тулити `run_loop` не задет — его политика задаётся фабрикой loop. `HARNESS_STRICT_VERIFY=1` возвращает сырой LS-вердикт для тулингов с нулевой толерантностью.

## [0.1.0] — 2026-10-05

### Added
- **MCP-выход репозитория (дорожная карта 2.1, фаза B):** stdio-сервер Model Context Protocol — `harness-mcp` / `python -m harness_mcp`. Тонкие адаптеры поверх готовых портов, новой движковой логики нет.
- **Пять тулингов (B2):** `ping` (версии пакетов + java/OneScript), `benchmark_info` (профиль бенчмарка: категории, сложность, покрытие L1 = 59/70 (84%), честные ограничения), `verify_module` (L0 через `BslVerifier.verify_module_text`), `run_loop` (полный цикл на `BslAgentLoop`, возвращает код и лог итераций), `eval_summary` (прогон бенчмарка, дефолт-лимит 10 задач — MCP-тулинг отвечает за секунды; полный набор явным `full: true`).
- **Протокол (B1):** JSON-RPC 2.0, одно сообщение на строку; `initialize` (capabilities + serverInfo), `notifications/*` без ответа, `tools/list`, `tools/call` (ошибки тулинга — `isError`, неизвестный тулинг — `-32602`, краш — `-32603`), стандартный `ping`. Провод ASCII-экранирован — пайп безопасен в любой локали, включая Windows-консоли.
- **Сессионное состояние (B3):** `SessionState` — кэш прогонов в памяти с TTL 15 минут и лимитом записей; `run_loop`/`eval_summary` возвращают `run_id`, агент переспрашивает детали без перезапуска цикла. Без персистентности — осознанное ограничение v0.1.
- **Инжектируемые сервисы:** фабрики loop/verifier подменяются в юнит-тестах — весь surface тулингов покрыт фейками (без сети/java/ключей), живой subprocess-smoke поднимает реальный сервер и вызывает все пять тулингов.
- README с тремя готовыми конфигами подключения: Claude Code, opencode, Cline.
